D3.js

D3 stands for "Data-Driven Documents." It's a JavaScript library that binds data to visual elements and lets you build any visualization you can imagine. Bar charts, yes. But also force-directed networks, animated maps, treemaps, arc diagrams, and things that don't have names yet. D3 doesn't give you pre-made charts. It gives you the building blocks to invent your own.

What People Make With It

  • The New York Times uses D3 for almost all their interactive data stories
  • Interactive election maps and real-time dashboards
  • Animated visualizations of climate data, migration patterns, music trends
  • Network graphs showing relationships between things (people, ideas, species)
  • Data art, where the line between chart and artwork disappears

The Code

force-graph.js 
// Define our data: art supply categories and tools
const nodes = [
  { id: "Drawing", group: 0 },
  { id: "Pencils", group: 0 },
  { id: "Charcoal", group: 0 },
  { id: "Digital", group: 1 },
  { id: "p5.js", group: 1 },
  // ... more nodes
];

const links = [
  { source: "Drawing", target: "Pencils" },
  { source: "Digital", target: "p5.js" },
  // ... more links
];

// Create the force simulation
const simulation = d3.forceSimulation(nodes)
  .force("link", d3.forceLink(links).id(d => d.id))
  .force("charge", d3.forceManyBody().strength(-200))
  .force("center", d3.forceCenter(w / 2, h / 2));

// Draw links as lines
const link = svg.selectAll("line")
  .data(links).join("line")
  .attr("stroke", "#ED8B00")
  .attr("stroke-opacity", 0.3);

// Draw nodes as circles
const node = svg.selectAll("circle")
  .data(nodes).join("circle")
  .attr("r", 12)
  .attr("fill", d => colors[d.group])
  .call(drag(simulation));

// Update positions each tick
simulation.on("tick", () => {
  link.attr("x1", d => d.source.x)
      .attr("y1", d => d.source.y)
      .attr("x2", d => d.target.x)
      .attr("y2", d => d.target.y);
  node.attr("cx", d => d.x)
      .attr("cy", d => d.y);
});

How It Connects to p5.js

In p5.js, you draw shapes by calling functions: circle(x, y, r). D3 takes a different approach. Instead of drawing shapes directly, you bind data to DOM elements and let D3 figure out the drawing. It's a different mental model, but the core idea is the same: turn data into visuals. If you've ever used arrays in p5.js to hold a bunch of objects and loop through them to draw... that's basically what D3 does, just with a fancier data-binding system. The physics simulation in the demo above? It's the same kind of thing as particles with forces in p5.js.
