CONTEXT FOR THE CREATIVE CODER

You're learning p5.js in class. But p5.js doesn't exist in a vacuum. It's part of a massive, wild, sometimes chaotic ecosystem called JavaScript. Here's the story of how we got here, and a map of the neighborhood you're moving into.

The JavaScript Story

From a 10-day hack job to the most popular programming language on Earth.

1995
Born in 10 Days

Brendan Eich, a developer at Netscape, writes the first version of JavaScript in literally 10 days. Not 10 months. Ten. Days. They called it "Mocha" at first, then "LiveScript," then slapped on "JavaScript" because Java was the hot language and they wanted to ride the hype. It was a marketing stunt. The name still confuses people 30 years later.

1996 - 1999
The Browser Wars

Netscape vs. Internet Explorer. Microsoft reverse-engineers JavaScript and makes their own version called JScript. Every browser does things differently. Writing code that works everywhere is a nightmare. Developers pull their hair out. The web is ugly, buggy, and wonderful.

2001 - 2004
The Dark Ages

"Real programmers" look down on JavaScript. It's considered a toy language, not worthy of serious work. Meanwhile, Flash dominates the creative web. Want to make something visual and interactive? You use Flash. JavaScript is mostly used for annoying pop-up ads and dropdown menus. Not exactly prestigious.

2005
The AJAX Revolution

Google Maps launches, and everyone's jaw drops. A full interactive map... running in a browser... with no page reloads? This is built with a technique called AJAX, and it proves that JavaScript can build real applications. Not just pop-ups. Actual software. The perception shifts overnight.

2006 - 2010
jQuery and Growing Up

jQuery arrives and makes JavaScript way less painful to write. Instead of fighting browser differences, developers can write code once and have it work everywhere. JavaScript starts to be taken seriously. Libraries and frameworks start popping up. The ecosystem is growing.

2008
Chrome's V8 Engine

Google releases Chrome with the V8 JavaScript engine, and suddenly JavaScript is fast. Like, actually fast. This is a big deal. Before V8, running complex programs in JavaScript was sluggish. Now it can handle real computation. This one engine changes everything that comes next.

2009
JavaScript Escapes the Browser

Ryan Dahl takes Chrome's V8 engine and uses it to create Node.js, which lets you run JavaScript outside the browser. On servers. On your computer. Anywhere. JavaScript is no longer trapped in a little browser window. It can do basically anything now. The "toy language" can build backends, command-line tools, robots... whatever.

2001 / 2013
Art Meets the Browser

In 2001, Ben Fry and Casey Reas create Processing, a Java-based tool that makes coding accessible to artists and designers. It changes how people think about creative coding. Then in 2013, Lauren McCarthy reimagines it for the web as p5.js. Same philosophy (code as a creative medium), but now it runs in any browser. No downloads, no installs. This is where you come in.

2015
Modern JavaScript is Born

ES6 (also called ES2015) lands, and JavaScript gets a massive upgrade. Arrow functions, classes, template literals, destructuring... the language finally feels modern. Most of the JavaScript you're learning in class uses ES6+ features. It's a way better language than the one Brendan Eich wrote in 10 days.

2020s
The Toy Language Won

JavaScript is now the most widely used programming language in the world. It runs websites, mobile apps, servers, desktop apps, games, art installations, robots, and machine learning models. The language that "real programmers" laughed at? It outlasted most of them. Not bad for something written in 10 days.

Every function you write, every variable you create, every loop you build... those are JavaScript skills. You're learning one of the most in-demand programming languages on Earth, just through a creative lens. That's actually kind of incredible.
