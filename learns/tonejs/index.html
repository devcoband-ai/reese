Tone.js

Tone.js turns your browser into a synthesizer, a drum machine, a music production tool. It's built on top of the Web Audio API (which is powerful but complicated) and makes sound synthesis, effects, and sequencing genuinely approachable. You can build instruments, generative music, sound installations, or just make cool noises. All in JavaScript.

What People Make With It

  • Browser-based synthesizers and drum machines
  • Generative music that composes itself
  • Interactive sound installations in galleries
  • Music visualizers that respond to audio in real time
  • Audio-reactive art paired with p5.js
  • Educational tools for learning music theory

The Code

synth.js 
// Create a synth with effects
const reverb = new Tone.Reverb(2).toDestination();
reverb.wet.value = 0.3;

const synth = new Tone.PolySynth(Tone.Synth, {
  oscillator: { type: "triangle" },
  envelope: {
    attack: 0.05,
    decay: 0.2,
    sustain: 0.5,
    release: 0.8,
  }
}).connect(reverb);

// Map keyboard keys to musical notes
const keyMap = {
  "a": "C4",
  "w": "C#4",
  "s": "D4",
  "e": "D#4",
  "d": "E4",
  "f": "F4",
  "t": "F#4",
  "g": "G4",
  "y": "G#4",
  "h": "A4",
  "u": "A#4",
  "j": "B4",
};

// Play a note when key is pressed
document.addEventListener("keydown", e => {
  const note = keyMap[e.key];
  if (note) synth.triggerAttack(note);
});

// Release when key is up
document.addEventListener("keyup", e => {
  const note = keyMap[e.key];
  if (note) synth.triggerRelease(note);
});

How It Connects to p5.js

p5.js has its own sound library (p5.sound) that handles basic audio playback and analysis. Tone.js is like the pro upgrade. It gives you synthesis, effects chains, scheduling, and way more control. But the concepts are similar: oscillators make waves, envelopes shape those waves over time, and you trigger things in response to events. You can even use Tone.js alongside p5.js to create audio-reactive visuals, where the shapes and colors on screen respond to the sounds being played. That combination (p5 for visuals, Tone for sound) is one of the most powerful creative coding setups you can build.
