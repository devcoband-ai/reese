GSAP

GSAP (GreenSock Animation Platform) is the animation library that professionals reach for when CSS animations aren't enough. It can animate anything: DOM elements, SVG paths, canvas objects, colors, numbers... basically any JavaScript property. It's what makes those jaw-dropping, buttery-smooth website animations you see on award-winning sites. And it's surprisingly friendly to learn.

What People Make With It

  • Scroll-triggered animations on storytelling websites
  • Complex UI transitions and micro-interactions
  • SVG morphing (one shape melting into another)
  • Animated text reveals, staggered entrances, parallax effects
  • Most of the sites that win Awwwards use GSAP somewhere

The Code

animations.js 
// GSAP makes complex animations readable
const shapes = ["#shape-1", "#shape-2", "#shape-3", "#shape-4", "#shape-5"];

// Bounce: staggered bounce animation
gsap.to(shapes, {
  y: -150,
  duration: 0.6,
  ease: "power2.out",
  stagger: 0.1,       // each starts 0.1s after the last
  yoyo: true,          // bounce back
  repeat: 1,
});

// Scatter: fly to random positions
shapes.forEach(s => {
  gsap.to(s, {
    x: random(-200, 200),
    y: random(-150, 150),
    rotation: random(-360, 360),
    duration: 1,
    ease: "elastic.out(1, 0.5)",
  });
});

// Wave: staggered sine-wave motion
gsap.to(shapes, {
  y: -100,
  duration: 0.8,
  ease: "sine.inOut",
  stagger: { each: 0.15, repeat: -1, yoyo: true },
});

// Morph: change shape, color, and size simultaneously
gsap.to("#shape-1", {
  borderRadius: "50%",
  width: 80,
  height: 80,
  backgroundColor: "#BBDDE6",
  rotation: 180,
  duration: 1,
  ease: "back.inOut(1.7)",
});

How It Connects to p5.js

In p5.js, when you want to animate something, you manually update values each frame in draw(). Something like x += speed or using lerp() to smooth things out. GSAP automates all of that. Instead of calculating positions frame by frame, you say "move this thing to there over 1 second with this easing" and GSAP handles every frame. It's like having a really smart animation assistant. The concepts are the same (position, rotation, scale, timing), but GSAP gives you easing curves, stagger effects, and timeline sequencing out of the box. You could absolutely use GSAP inside a p5.js project too.
