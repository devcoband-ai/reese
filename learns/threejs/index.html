Three.js

Three.js is JavaScript's gateway to 3D. It takes the browser's built-in WebGL rendering (which is powerful but brutally complex to use raw) and wraps it in an approachable API. You create scenes, add lights, place objects, and move a camera around... all in code. Think of it like p5.js, but in three dimensions instead of two.

What People Make With It

  • Interactive 3D product showcases for brands
  • Browser-based games and virtual worlds
  • Data visualizations in three dimensions
  • Digital art installations and generative sculpture
  • Award-winning websites like Bruno Simon's portfolio (you drive a car around his resume)

The Code

sculpture.js 
// Create the scene, camera, and renderer
const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(60, w / h, 0.1, 100);
camera.position.set(0, 0, 4);

const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(w, h);

// Create the geometry (an icosahedron we'll distort)
let geo = new THREE.IcosahedronGeometry(1.5, detail);

// Distort each vertex using noise
const positions = geo.attributes.position;
for (let i = 0; i < positions.count; i++) {
  const v = new THREE.Vector3().fromBufferAttribute(positions, i);
  const noise = simplex3(v.x * 2, v.y * 2, time);
  v.multiplyScalar(1 + noise * distortion);
  positions.setXYZ(i, v.x, v.y, v.z);
}

// Material with shifting colors
const mat = new THREE.MeshStandardMaterial({
  color: new THREE.Color().setHSL(colorShift, 0.7, 0.5),
  roughness: 0.3,
  metalness: 0.6,
  wireframe: showWireframe,
  flatShading: true
});

// Lights
scene.add(new THREE.AmbientLight(0x404040));
const light = new THREE.PointLight(0xffffff, 1.5);
light.position.set(5, 5, 5);
scene.add(light);

// Animate
function animate() {
  requestAnimationFrame(animate);
  mesh.rotation.y += 0.005;
  renderer.render(scene, camera);
}

How It Connects to p5.js

In p5.js, you think about a canvas, shapes, colors, and a draw loop that runs every frame. Three.js works the same way, just with an extra dimension. Instead of ellipse(x, y, w, h) you have meshes and geometries. Instead of fill() you have materials. The animation loop? Same concept as draw(), just called requestAnimationFrame(). If you can think in p5.js, you can think in Three.js. You already understand the mental model.
