CREATIVE / VISUAL

p5.js

p5.js is a JavaScript library that makes coding accessible for artists, designers, educators, and beginners. It's a friendly canvas. You write a few lines of code, and shapes, colors, and motion appear on screen. It was created by Lauren McCarthy in 2013 as a web-native version of Processing, with the philosophy that code is just another creative medium... like paint or clay or charcoal.

What People Make With It

  • Generative art that creates itself differently every time it runs
  • Interactive installations in galleries and museums
  • Data visualizations that turn numbers into visuals
  • Experimental animations and visual poetry
  • Creative tools and instruments that respond to input
  • Thousands of sketches on OpenProcessing

Try It: Generative Garden

Use the sliders to change what grows. Each combination makes something different.

The Code

sketch.js 
let flowers = [];
let petals = 6, hueBase = 200, speed = 1, maxSize = 50;

function setup() {
  let canvas = createCanvas(800, 400);
  canvas.parent('p5-canvas');
  colorMode(HSB, 360, 100, 100, 100);
  noStroke();
}

function draw() {
  background(320, 80, 8, 15); // slow fade

  // spawn new flowers at mouse or randomly
  if (frameCount % floor(10 / speed) === 0) {
    flowers.push({
      x: mouseIsPressed ? mouseX : random(width),
      y: mouseIsPressed ? mouseY : random(height),
      size: 0,
      maxS: random(maxSize * 0.5, maxSize),
      hue: (hueBase + random(-30, 30)) % 360,
      rotation: random(TWO_PI)
    });
  }

  // draw and grow each flower
  for (let f of flowers) {
    f.size = lerp(f.size, f.maxS, 0.02 * speed);
    f.rotation += 0.005 * speed;
    push();
    translate(f.x, f.y);
    rotate(f.rotation);
    for (let i = 0; i < petals; i++) {
      fill(f.hue, 70, 90, 60);
      ellipse(0, f.size * 0.4, f.size * 0.35, f.size);
      rotate(TWO_PI / petals);
    }
    fill(f.hue + 40, 90, 100);
    circle(0, 0, f.size * 0.25);
    pop();
  }

  // remove old flowers to keep performance smooth
  if (flowers.length > 80) flowers.splice(0, 1);
}

This Is Home Base

p5.js is where you're building your creative coding foundation. Every concept you pick up here (variables, loops, functions, objects, conditionals) is just plain JavaScript. When you write ellipse(x, y, w, h), you're calling a JavaScript function. When you use let to store a value, that's the same let used in React apps and Node.js servers. The other tools in this section (Three.js, D3, GSAP, Tone.js, ml5) all work the same way. Different libraries, same language. You're not learning a niche tool. You're learning JavaScript through the best possible door: the creative one.
