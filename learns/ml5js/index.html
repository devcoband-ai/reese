ml5.js

ml5.js makes machine learning approachable for creative coders. It wraps TensorFlow.js (Google's ML library) in a friendly API designed to work with p5.js. You can detect body poses, classify images, generate text, recognize hand gestures, and more... all running right in the browser. No server, no Python, no PhD required.

What People Make With It

  • Interactive installations where your body controls the visuals
  • Hand-tracking musical instruments you play with gestures
  • Art that responds to your facial expressions
  • Image classifiers that identify objects in real time
  • Creative tools that learn from your drawing style
  • Accessible interfaces controlled by body movement

Try It: Body Pose Tracker

This uses your webcam to detect body poses in real time. The skeleton is drawn with p5.js. Move around and watch it follow you. (Your video stays in your browser, nothing is sent anywhere.)

pose-tracker.js
Click "Start Camera" to begin. Your webcam feed stays local, nothing leaves your browser.

The Code

pose-tracker.js 
let video, bodyPose, poses = [];
let pointSize = 10;

// p5.js setup: create canvas and start webcam
function setup() {
  createCanvas(640, 480);
  video = createCapture(VIDEO);
  video.hide();

  // Initialize ml5 body pose detection
  bodyPose = ml5.bodyPose(video, () => {
    console.log("Model loaded!");
  });

  // When poses are detected, update our array
  bodyPose.detectStart(video, results => {
    poses = results;
  });
}

function draw() {
  image(video, 0, 0);

  // Draw each detected pose
  for (let pose of poses) {
    // Draw skeleton connections
    for (let connection of bodyPose.getSkeleton()) {
      stroke(249, 66, 58);
      strokeWeight(2);
      line(connection[0].x, connection[0].y,
           connection[1].x, connection[1].y);
    }

    // Draw keypoints (joints)
    for (let kp of pose.keypoints) {
      if (kp.confidence > 0.3) {
        fill(237, 139, 0);
        noStroke();
        circle(kp.x, kp.y, pointSize);
      }
    }
  }
}

How It Connects to p5.js

ml5.js was literally designed to work with p5.js. They share the same philosophy: make powerful technology accessible to creative people. The demo above uses p5.js for the canvas, the webcam capture, and all the drawing. ml5 just adds the intelligence layer on top. The pose data you get back? It's just arrays of x, y coordinates and confidence scores. You already know how to work with those in p5.js. The magic is that now those coordinates come from a neural network analyzing video in real time. Same drawing skills, wildly different input.
